# moneyforward-mcp

Money Forward ME の入出金を読み、二重に数えられている取引を探して直すための、ローカルの MCP サーバです。MF ME には公式の API がないので、ログイン済みの Chrome を Playwright で操作します。

## 準備

```bash
cd moneyforward-mcp
npm install
npm run login
```

`npm run login` で開いた Chrome に、ご自身でログインします（Google でのログインも使えます）。入出金のページが表示されたら、その Chrome を ⌘Q で終了してください。終了すると、ログインできたかを自動で確かめます。いつもの Chrome とは別に起動するので、⌘Q はログイン用の方に押してください。

ログインの状態は `~/.moneyforward-mcp/chrome-profile` に残り、MCP サーバはこのプロファイルを使います。パスワードはこのリポジトリのコードを通りません。Playwright から開いた Chrome では Google ログインが拒否されるので、ログインのときだけは普通の Chrome を起動しています。

Claude Code に登録します。

```bash
claude mcp add moneyforward -- node /path/to/userscripts/moneyforward-mcp/server.js
```

## ツール

| ツール | すること |
| --- | --- |
| `list_transactions` | 指定した月の範囲（最大 24 か月）の入出金を読む |
| `find_duplicates` | 二重に数えられている取引を探す。何も変えない |
| `set_calc_target` | 取引を計算対象外（または計算対象）にする |
| `set_transfer` | 取引を振替にし、相手側の入出金を振替先に結びつける |

`set_calc_target` と `set_transfer` は、ページを読み込み直して保存された値を確かめてから、結果を返します。どちらも MF の画面から元に戻せます。取引を削除するツールはありません。変更した内容は `~/.moneyforward-mcp/audit.log` に 1 行ずつ記録します。

## 重複とみなす条件

- **自分名義の振込**（`own_transfer`）: 銀行口座からの「振込」の出金と、別の銀行口座への入金が、同じ名義・同じ額で、3 日以内にある。振替にする
- **二重の連携**（`duplicate_link`）: 2 つの連携（例: モバイル Suica を 2 つの ID で連携）の期間が重なり、その中でどちらの取引も 9 割以上が日付・金額・内容まで一致する（3 件以上）。更新が先に止まった方の、一致した取引だけを計算対象外にする
- **通販とカード**（`shop_card`）: Amazon・Yahoo!ショッピングの購入履歴の数件（品物・送料・ポイント・クーポン）の合計が、その 1 日前から 10 日後までのカード明細の 1 件と一致する。カード側を計算対象外にする

計算対象外の取引は判定に使わないので、直したあとに同じ期間をもう一度調べても、同じ操作は提案されません。

## 注意

- MF はヘッドレスの Chrome を拒否する（403）ので、ツールを使っている間は Chrome のウィンドウが開きます。User-Agent を偽ってこの制限を避けることはしていません
- MCP サーバと `npm run login` は同じプロファイルを使うので、同時には動かせません
- 画面のクラス名やフォームに依存しているので、MF の画面が変わると動かなくなります
- 自動での操作が MF の利用規約に触れないかは、利用者自身で確かめてください

## テスト

```bash
npm test
```

重複の判定（`lib.js`）だけをテストします。MF の画面を操作する部分（`mf.js`）は、実際のアカウントで動かして確かめています。
