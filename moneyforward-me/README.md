# moneyforward-me

Money Forward ME（家計簿）の画面を作り直し、使いやすくする userscript です。Tampermonkey や Violentmonkey に `moneyforward-me.user.js` を読み込んで使います。

## 画面の構成

- 上部のメニューを左のサイドバーにまとめる。開いているページのグループだけ、下位のメニューも表示する
- 広告の列を隠し、本文をサイドバーを除いた幅いっぱいに広げる
- 入出金ページは一覧を中心にする。説明文を隠し、月の収入・支出・収支を数字のカードで表示する。カレンダーはボタンで開閉でき、開閉の状態はブラウザに保存する
- 入出金の一覧は行の高さを詰め、金額を右に寄せて、収入と支出を色で分ける
- カレンダーは、日付を左上に小さく置き、支出の金額を太字にする。日ごとの支出の多さをマスの下端の赤い棒の長さで示し（月でいちばん多い日が全幅）、前後の月の日付と金額は薄くする。手入力の鉛筆はマスにマウスを乗せたときだけ濃く表示する
- ホームは総資産・入出金・口座などをカードに分けて並べる

## ダークモード

サイドバーの下のボタンで、自動・ライト・ダークを順に切り替えます。自動のときは OS の設定に従います。選んだ値はブラウザに保存します。

Money Forward ME の画面は色を直接指定した箇所が多いので、要素の実際の色を読み、明るい背景・暗い文字・明るい枠線を暗い配色の値に置き換えています。グラフは canvas に描かれているため、明暗を反転して表示します。

## グラフ

ホーム・収支内訳・月次推移・資産内訳・資産推移のグラフ（どれも MF の Chart.js）の見た目を、まとめて差し替えます。

- 目盛りは横の細い罫線だけにし、金額は「120万」のように丸める。横軸の日付は「10/1」「5月」と短くして、斜めに傾けない
- 棒は角を丸め、太さの上限を決める。積み上げの棒は一番上だけ丸め、項目の境目に地の色の細い隙間を入れる
- 円グラフはドーナツにして、穴に合計を書く。収支内訳の 2 重の円は、外側が中項目、内側が大項目になる
- 資産推移の積み上げの面は、層ごとに塗り分けて、色が重なって濁らないようにする
- 月次推移に、各月の収支（収入 − 支出）の折れ線を足す
- 棒と線のグラフは、マウスを乗せた位置（月や日）の全項目を、金額の大きい順にツールチップに並べる
- ダークモードでは、グラフを反転させずに、文字・罫線・ツールチップの色を配色に合わせて描き直す

収支内訳の表の「割合」の列には、いちばん大きい項目を全幅とした棒を敷きます。

## アニメーション

ページを開くと、カードやメニューが少しずつ浮き上がるように現れます。月の収入・支出・収支の数字はカウントアップし、テーマを切り替えると画面がクロスフェードします。OS で「視差効果を減らす」を設定しているときは動かしません。

## そのほかの機能

- 入出金の一覧の上に検索欄を置き、内容・カテゴリ・金額・メモで行を絞り込む。空白で区切った語をすべて含む行だけが残り、`1000` で `1,000` にも当たる
- 保有金融機関の見出しの下の選択欄で、口座ごとに行を絞り込む。選択肢は件数の多い順に並び、検索欄と組み合わせて使える
- 大項目が「未分類」の行に色を付ける
- ← → キーで前月・次月に移る。入出金のほか、収支内訳でも使える（入力欄にカーソルがあるときと、MF のダイアログを開いているときは動かない）
- `/` キーで入出金の検索欄に移る（MF のダイアログを開いているときは移らない）。検索欄で Esc を押すと語を消し、もう一度押すと欄から抜ける

## テスト

node --test moneyforward-me/
